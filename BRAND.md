# Lexicon · Brand identity

**Status: Official (approved October 28, 2026)**

The approved Lexicon logo is the minimalist **L-shaped mark** in blue with a coral circle. This replaces the original `L.` placeholder and `LX` top-right placeholder.

## Primary logo

![Lexicon official icon](./lexicon-logo.svg)

**Canonical vector asset:** [lexicon-logo.svg](./lexicon-logo.svg)

This file is the source of truth. The dashboard embeds the same vector geometry and colors directly to avoid icon-caching problems, and the browser tab uses a corresponding inline vector favicon.

### Brand palette

| Role | Hex |
| --- | --- |
| Primary blue | `#3B82F6` |
| Deep blue | `#2258C7` |
| Coral accent | `#FF7A59` |
| Light coral | `#FFA88E` |
| Icon background | `#F8FAFC` |
| Dashboard background | `#080E1A` |

The icon's rounded L is blue with a subtle deep-blue gradient; its lower right circular accent blends light coral into coral. The background is a soft off-white.

### Use

- **Lexicon sidebar:** icon beside the product name.
- **Top-right dashboard:** matching small icon.
- **Browser tab:** inline SVG favicon.
- **Installable web app:** [site.webmanifest](./site.webmanifest) references the canonical icon.
- **GitHub:** README and brand documentation reference the same vector.

Use the artwork on light or dark UI surfaces, preserving its off-white rounded square. Keep generous padding around the mark. Avoid replacing the circle with arbitrary shapes, applying a gold or luxury treatment, or changing its proportions.

## Brand voice

**Lexicon** is friendly, calm, clear, modern, and practical. It is a personal learning space, not a formal institution or luxury product. Its features and visual identity should feel approachable while remaining thoughtfully designed.
